# 2026-10-06 — เลือกโมเดลแชท, หน้า Admin, โปรไฟล์, โหลดประวัติ CSV

## สิ่งที่ทำ

- **เลือกโมเดลตอนสร้างแชทใหม่**
  - ตัวเลือก Gemini 3.1 Flash-Lite (ตัวเก่า, ค่าเริ่มต้น) และ Gemini 3.5 Flash-Lite (ตัวใหม่)
  - โมเดลผูกกับแชทนั้นตลอด แชทเก่าที่ไม่มีค่าถือเป็น 3.1
  - เปลี่ยนเฉพาะโมเดลที่ตอบแชท (system prompt และการตั้งค่า generation เหมือนเดิม) RAG, embedding, สรุปผู้ป่วย, ประเมินผล ยังใช้โมเดลเดิม
  - ชื่อโมเดลใหม่ตั้งได้ด้วย `CHAT_MODEL_NEW` ใน `.env`
  - Sidebar แบ่งหมวดตามโมเดล แล้วค่อยแบ่งตามวัน
  - log ตอนตอบพิมพ์ `[RAG] answering with model: ...` (บรรทัด `[RAG] Chat model: 3.1` ตอนเปิดเซิร์ฟเวอร์คือโมเดลเริ่มต้น ไม่ใช่โมเดลของแชทนั้น)
- **Popup สร้างแชท**: การ์ดเลือกโมเดลขนาดใหญ่ แอนิเมชันตอนเปิดปิด กด Esc หรือคลิกพื้นหลังเพื่อปิด
- **โหลดประวัติผู้ป่วย** ที่หน้า `/patients`: ปุ่มบนการ์ดแต่ละคน ดาวน์โหลด CSV (`chat-history-<ชื่อ>.csv`) รวมทุก session พร้อมโมเดลที่ใช้ เปิดใน Excel ได้
- **หน้า Admin ใหม่** (`/admin`, เฉพาะ admin)
  - การ์ดสรุปภาษาง่าย, เช็กลิสต์ความปลอดภัย, ตารางผู้ใช้, ประวัติการใช้งาน (กรองได้, ดาวน์โหลด CSV), รีเฟรชเองทุก 30 วินาที
  - จัดการผู้ใช้: เพิ่ม, รีเซ็ตรหัสผ่าน, เปลี่ยนบทบาท, ปิด/เปิดบัญชี, ปลดล็อกการ login
  - ตารางแชทล่าสุดของทุกคน (ชื่อผู้ป่วย, เจ้าของ, แผนก, โมเดล, จำนวนข้อความ, เวลา) เพราะตัวเลขสรุปอย่างเดียวไม่โชว์แชทใหม่
  - ไม่มีหน้าเปลี่ยนรหัสผ่านใน Admin
- **หน้าโปรไฟล์** (`/profile` และ `/profile/<username>`)
  - แก้ชื่อที่แสดง และเลือกแผนก (ผู้ป่วยนอก, ผู้ป่วยใน, ห้องจ่ายยา, ฉุกเฉิน, กุมารเวชกรรม)
  - ผู้ใช้ทั่วไปแก้ได้เฉพาะของตัวเอง admin แก้ให้คนอื่นได้
  - กดชื่อตัวเองที่ sidebar เพื่อเข้าโปรไฟล์
- **โลโก้ PharmaCare AI มุมซ้ายบน** ของหน้า Admin, รายการผู้ป่วย, ประวัติผู้ป่วย, โปรไฟล์ กดแล้วกลับหน้าหลัก
- **Frontend build**: แยกโค้ดตามหน้า (หน้าล็อกอินไม่ต้องโหลด pdf.js/xlsx ทั้งก้อน) และเลิกเตือน chunk ใหญ่ของ pdf.js worker
